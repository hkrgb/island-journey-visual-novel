# 離島旅程 · Visual Novel

《離島旅程》16:9 網頁視覺小說。

## 網站

- 正式版：https://island-journey-rgb.web.app
- Firebase project：`island-journey-rgb`

## 發布

`main` 分支更新後，GitHub Actions 會自動發布 `output/` 到 Firebase Hosting。
Pull Request 會建立臨時預覽網址，合併前可先檢查效果。

## 素材

遊戲使用的公開素材位於 `output/assets/`。小說原稿、工作檔、原始短片及臨時檔由 `.gitignore` 排除，只保留在本機。
